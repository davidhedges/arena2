Status: **Archived in place and superseded on 2026-08-26. Do not translate,
extend, or use as a progression/loadout source of truth.**

old school-as-discipline catalog shape. Both conflict with
`docs/combat-build-progression-cutover-plan-2026-08-26.md`.
