# Animated Surface Shaders

A small library for animated environment surfaces (lava now; poison, blood,
shadow corruption, arcane floors later). Built for URP 17 / Unity 6 as
hand-written HLSL, matching this project's existing shader convention. It is
deliberately **not** an uber-shader: shared math lives in `Common/`, and each
surface type is its own small shader that composes those pieces.

## Layout

```text
Shaders/
  Common/
    AnimatedSurface.hlsl    Reusable animation building blocks (pure functions).
  Environment/
    LavaSurface.shader      "Arena/Environment/LavaSurface" — first surface type.
```

Related content:

- Material: `Assets/Arena/Content/Art/Environment/Lava/M_Lava_FireShoreMagma.mat`
  — a migrated **duplicate** of the Stylized Materials Bundle's
  `M_FireShore_Magma`. The original asset-store material and textures are
  untouched; the duplicate references the pack's textures by GUID.
- Flow map: `Assets/Arena/Content/Art/Environment/Lava/T_Lava_FireShoreMagma_Flow.tga`
  — generated by `ops/generate_flow_map.py` (stdlib-only; run with no
  arguments to regenerate).
- Demo scene: `Assets/Arena/Content/Scenes/Authoring/LavaSurfaceDemo.unity`
  — a 2×2 field of lava planes (world-space UV, so the surface continues

  shadow onto the lava. Scenes under `Scenes/Authoring/` are excluded from

## Architecture

### `Common/AnimatedSurface.hlsl` — the reusable blocks

Pure functions only. No material CBUFFER state, no texture declarations, no
knowledge of any surface type. Extracted because every animated surface we
plan (poison, blood, arcane, ...) needs exactly these five operations; nothing
else was extracted because nothing else is yet proven to repeat.

| Function | Purpose |
| --- | --- |
| `AnimatedSurfaceUV` | Chooses mesh UV or world-space XZ planar UV (branchless lerp, no variant), applies tiling/offset. |
| `FlowUV` | Constant-velocity UV scroll from a direction vector, speed, and time. |
| `RotateUV` | Rotates UVs; putting one layer on a rotated grid keeps layer tilings from ever aligning into a visible repeat. |
| `NoiseDistortionUVOffset` | Two decorrelated scrolling samples of one noise texture become an evolving 2D UV offset — the "internal churn". Outputs the raw noise value for reuse. |
| `DecodeFlowVector` | Decodes a flow-map RG sample (0..1, 0.5 = still) into a signed 2D direction scaled by strength. |
| `FlowMapPhases` | Valve-style ping-pong advection: two half-period-offset UV phases plus their crossfade weight, so per-pixel flow never smears (each phase snaps back while its weight is zero). |
| `FlowedSampleRGB` | Samples a color texture at both flow phases and crossfades — the standard consumption of `FlowMapPhases`. |
| `DualLayerWeight` | Blend weight for two layers from per-layer scalar "heights" (any signal: emission luminance, height map, mask), with balance + sharpness controls. |
| `BlendLayerNormals` | Normalized lerp of two tangent-space normals by the layer weight. |
| `EmissionPulse` | Sine brightness multiplier around 1 with a spatial phase input, so pulsing travels across the surface instead of throbbing globally. |

### `Environment/LavaSurface.shader` — the composition

Opaque, fully lit URP shader (four passes):

- **ForwardLit** — the interesting one. The core motion is **per-pixel flow-map
  advection**: every point creeps along its own local direction from an
  RG flow map (Valve ping-pong technique — two half-period phases crossfaded so
  the advection reset is never visible). On top of that, two copies of the
  texture set drift gently in different global directions, with layer 2 on a
  rotated, rescaled UV grid so the two tilings can never align into a visible
  repeat (the flow vector is mapped into that rotated space so both layers
  advect in the same world direction); both layers' UVs are warped by the
  noise offset (layer 2 subtracts it, for extra decorrelation), and a
  low-frequency macro tap varies emission at meter scale to hide residual
  repetition.
  The layers are blended by *which one is locally hotter* (emission luminance
  through `DualLayerWeight`), so glowing veins keep surfacing through the
  blend — this, plus the noise warp, is what makes it read as circulating
  molten rock rather than sliding wallpaper. Lighting goes through URP's
  `UniversalFragmentPBR`, so shadows, Forward+ clustered lights, SSAO, and fog
  all behave exactly like URP Lit.
- **ShadowCaster / DepthOnly / DepthNormals** — URP's stock pass includes,
  reused directly (with alpha-test off they touch no material properties).
  Nothing is forked from the pipeline.

Perf notes (desktop, many tiles):

- 16 texture samples per pixel (flow-map advection double-samples each content
  texture for the phase crossfade), no per-pixel branches, no keywords for the
  feature set (world-space UV is a lerp, not a variant).
- Variant space is intentionally small: the realtime lighting/shadow keywords
  this project's Forward+ renderer uses, plus reflection-probe
  blending/box-projection/atlas and DBuffer decals (both enabled in the PC
  pipeline, so lava matches URP Lit's probe and decal behavior). Lightmapping,
  light cookies, light layers, and shadowmask keywords are omitted — add them
  to the pragma list if the project adopts those features. The surface samples
  light probes (`SampleSH`)
  for ambient; it is not meant to be lightmapped, and animated emission cannot
  meaningfully bake anyway (no Meta pass).
- DepthNormals outputs the geometric normal (skips the whole animation chain in
  the prepass); SSAO on emissive lava is visually negligible.
- Single `UnityPerMaterial` CBUFFER shared verbatim by all passes → SRP-batcher
  compatible.

## Lava material properties

**Surface**

| Property | Meaning |
| --- | --- |
| `Albedo` (+ tiling/offset) | Base color texture. Its tiling/offset is the *master* tiling for every layer, in both UV modes. In world-space mode, tiling is repeats per meter (the demo material uses 0.35 → one repeat per ~2.9 m). |
| `Tint` | Multiplies albedo. |
| `Smoothness` / `Metallic` | Standard PBR scalars. Lava reads best low-smoothness, non-metallic. |

**Flow**

| Property | Meaning |
| --- | --- |
| `Flow Map (RG)` | Per-texel flow direction (R = X, G = Y, 0.5 = still). **Must be imported linear (sRGB off).** Generated from the magma height map by `ops/generate_flow_map.py` (rotated-gradient/curl of the blurred height field: divergence-free swirls that circulate around height features and tile seamlessly). Regenerate or repaint freely; a neutral gray texture disables advection. |
| `Flow Map Tiling` | Flow-field UV scale relative to base UV — keep well below 1 so flow cells span meters. |
| `Flow Strength` | UV distance advected per cycle. The main "how alive is it" knob. |
| `Flow Cycle Speed` | Ping-pong cycles per second. Lower = slower, statelier creep (default 0.1 = 10 s cycles). |
| `Layer 1/2 Drift Direction (XY)` | Gentle global scroll per layer, layered under the advection. Magnitude also scales speed. |
| `Layer 1/2 Drift Speed` | Drift speed per layer (UV units/sec before tiling). |
| `Layer 2 UV Scale` | Extra tiling multiplier on layer 2 so the two layers never phase-lock (avoid 1.0 and neat ratios like 2.0; below 1.0 reads as a broader, deeper layer). |
| `Layer 2 Rotation` | Fixed rotation of layer 2's UV grid. The strongest anti-tiling lever: with any non-trivial angle the two layers' repeats can never line up into a grid. |
| `Layer Balance` | Shifts the blend toward layer 1 (0) or layer 2 (1). The scrolling noise also jitters this internally, so layer dominance migrates across the surface. |
| `Layer Blend Sharpness` | 0 = soft crossfade; higher = hard "hotter layer wins" veining. |

**Distortion**

| Property | Meaning |
| --- | --- |
| `Noise (R)` | Single-channel tileable noise. The magma **height map** (`T_FireShore_Magma_H`) is used — the pack ships no dedicated noise texture, and its soft cloudy height map is ideal. |
| `Noise Tiling` | Noise UV scale relative to base UV (below 1 = broad swirls). |
| `Distortion Amount` | UV warp strength. 0 = straight scrolling. **Effective warp scales with the noise texture's contrast** — the soft magma height map only spans roughly 0.2–0.5, so it needs values several times higher (~0.2+) than a full-range noise would. |
| `Distortion Speed` | How fast the warp field itself evolves. |

**Macro Variation**

| Property | Meaning |
| --- | --- |
| `Macro Variation` | Meter-scale brightness variation (mostly on emission, mildly on albedo) from one extra low-frequency noise tap. Repetition reads mostly through emission on a glowing surface, so this is what breaks the residual grid at distance. 0 disables. |
| `Macro Tiling` | UV scale of that variation relative to base UV — keep far below the texture tile frequency (default 0.07 ≈ one variation cell per ~14 texture repeats). |

**Normals**

| Property | Meaning |
| --- | --- |
| `Normal Map` | Sampled twice with the same flowing UVs as albedo. |
| `Normal Strength` | 0 flattens, 2 exaggerates. |

**Emission**

| Property | Meaning |
| --- | --- |
| `Emission Map` | HDR emission source, layered/blended like albedo. Its luminance also drives the layer blend. |
| `Emission Color` | HDR tint. |
| `Emission Intensity` | Scalar multiplier on top of the color (kept separate so pulsing/tuning doesn't fight the HDR color picker). |
| `Pulse Amount` | 0 = steady glow; 1 = full-depth brightness waves. |
| `Pulse Speed` | Pulse frequency (Hz-ish). The pulse phase comes from the distortion noise, so brightness waves travel across the surface. |

**Advanced**

| Property | Meaning |
| --- | --- |
| `World Space UV` | Off = mesh UVs. On = planar world XZ (1 unit = 1 UV before tiling): adjacent floor tiles form one continuous surface with zero seams and the texture doesn't stretch with mesh scale. |

## Building the next surface (poison, blood, arcane, ...)

1. Copy `Environment/LavaSurface.shader`, rename the shader path (e.g.
   `Arena/Environment/PoisonSurface`) and the vertex/fragment function names.
   The ShadowCaster/DepthOnly/DepthNormals passes and the CBUFFER pattern come
   along unchanged.
2. Keep the skeleton of the fragment: `AnimatedSurfaceUV` →
   `NoiseDistortionUVOffset` → two drift layers → `FlowMapPhases` advection →
   `DualLayerWeight` → `UniversalFragmentPBR`. Surfaces that don't need
   per-pixel flow (e.g. a static arcane rune floor) can drop the flow map and
   halve the content samples.
3. Change what the *surface* means, not the machinery — pick the layer-weight
   signal (poison: noise value for oily patches; blood: height map for
   coagulation), the pulse usage (arcane: pulse a rune mask instead of global
   emission), colors, and defaults.
4. If a genuinely new block emerges (e.g. directional flow-map sampling,
   vertex displacement), add it to `Common/AnimatedSurface.hlsl` as another
   pure function — only once a second surface actually needs it.

The forward-pass boilerplate (Varyings/InputData setup) intentionally lives in
each surface shader for now; hoist it into `Common/` only when the second or
third surface proves the shape is stable (rule of two).

## Known limits

- No Meta pass: emission does not contribute to baked GI (animated emission
  cannot bake meaningfully). Use a realtime point light for large gameplay
  areas if lava should light surroundings dynamically.
- No motion-vector pass: TAA treats the surface as static geometry (UV
  animation does not produce motion vectors anyway).
- World-space UV mode assumes a mostly horizontal surface (planar XZ
  projection); use mesh UVs for walls or steep flows.
- Flow-map ping-pong adds a subtle periodic "breathing" as the phases
  crossfade; the dual-layer blend masks most of it. If it ever reads as a
  pulse, lower `Flow Strength` before touching `Flow Cycle Speed`.
- Advection draws the flow field's streamlines: if the surface reads as
  uniform "squiggly brush strokes", the smear length (`Flow Strength`) is too
  close to the flow-cell size. Lower `Flow Strength`, lower `Flow Map Tiling`,
  or regenerate the flow map with a larger `--blur-radius` — coherent currents
  come from smear ≪ cell size.
